Subject fills the canvas nicely with clear silhouette, keyboard pointing diagonally up to the right, balanced compact landscape composition, soft studio light, tactile matte plastic, crisp soft shadows, sophisticated playful editorial toy render, no shiny metal, no photoreal desk, no black outlines.
